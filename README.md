1. "Librería" vs "paquete" — ¿es lo mismo?

Casi. Son términos que se usan medio intercambiables pero técnicamente:

Librería (library): el código en sí, la funcionalidad que escribes (ej: funciones para validar RUT, calcular dígito verificador, formatear, etc.)
Paquete (package): es la librería empaquetada con metadata (nombre, versión, dependencias) lista para distribuir e instalar con un gestor de paquetes (pip, npm, etc.)
